# Dylan Cerrudo - Portfolio

My personal site, built with Next.js and three.js. Work in progress.

## The plan

- A 3D globe of the tech I work with, built from scratch in three.js
- My experience and projects, all driven from one content file
- Deployed on Vercel with a custom domain

## Stack

- Next.js 16 (App Router), React 19, TypeScript
- Tailwind CSS v4
- three.js with React Three Fiber
